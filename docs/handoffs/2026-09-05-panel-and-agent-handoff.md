### نیازهای قطعی پنل
- تک‌ادمین، ساده، موبایل‌فرندلی، فارسی RTL.
- bot به کار خودکار ادامه دهد.
- خبرهایی که سردبیر رد/تأیید نمی‌کند وارد review queue شوند (به‌جز موارد کاملاً stale/malformed طبق طراحی).
- در پنل بتوان عنوان و متن فارسی را قبل از تأیید ویرایش کرد.
- Publish در پنل باید همان لحظه مستقیم به Telegram بفرستد، نه منتظر run بعدی بماند.
- Reject دستی وجود داشته باشد.
- مدیریت منابع سایت، X/Twitter و منابع مرجع لازم باشد.
- افزودن X با handle انجام شود؛ نه Telegram ID.
- منبع جدید نباید بدون عبور از قواعد سردبیر trusted تلقی شود.
- secretها هیچ‌وقت در UI یا repo commit نشوند.
