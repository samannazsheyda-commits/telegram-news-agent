# Bikhabar Panel V3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild the VPS-first newsroom panel into a fast Persian-first operational dashboard with clean live feed, working source management, collapsible module previews, and live air-traffic presentation.

**Architecture:** Flask remains the authenticated control surface while the agent/runtime owns all network-heavy work. The dashboard consumes lightweight local JSON APIs and enqueues runtime commands. Editorial cleanup happens before primary feed presentation; original source text stays available only on demand.

**Tech Stack:** Python 3, Flask, Jinja2, vanilla JavaScript, CSS, pytest, existing runtime JSON repository, OpenSky/ADSB.lol/airplanes.live.

**Spec:** `docs/superpowers/specs/2026-09-09-panel-v3-design.md`

## Global Constraints
- No external network fetch during main dashboard HTML rendering.
- Default news feed is Persian RTL; original English is hidden behind an explicit expander.
- Live feed polling target is 1 second with overlap protection.
- Reject article/question/opinion/explainer/noise before primary feed display.
- Keep VPS runtime state authoritative and persistent.
- Air traffic is real provider data only; no fabricated aircraft.
