# Editorial monitoring rules update

This change prioritizes Iran security developments over low-value corporate coverage.

- Deduplicate the same underlying event/claim across all monitored outlets and across runs.
- Retain a 72-hour published-story window for cross-source duplicate checks.
- Filter routine company/CEO/profit/growth/fleet/route stories unless they contain direct operational security relevance.
- Target direct searches for IRGC/Quds Force, Mohsen Rezaei, Khatam al-Anbiya, Iranian Army, Iranian ballistic/cruise missiles and drones, energy infrastructure, Benjamin Netanyahu, and Israel Katz.
- Critical security stories can be considered for up to 72 hours when newly discovered; normal commentary/question/vague filters still apply.
- Prefer source-page subheadline/description for detail enrichment, then lead paragraphs.
- Do not force news descriptions to a fixed sentence/line count.
